## Migration tool

`npx jscodeshift@latest ./src/ --extensions=ts,tsx --parser=tsx --transform=./node_modules/@tanstack/react-query/build/codemods/src/v5/remove-overloads/remove-overloads.cjs`. It rewrites `useQuery`/`useMutation`/`useInfiniteQuery`/`queryClient.*` overloads to the single-object form. Check the path in the installed package; it covers only the overloads.

## Upgrade path

Direct 4 → 5. Requires React 18+ and TypeScript 4.7+.

## Must move together

`@tanstack/react-query-devtools`, `@tanstack/react-query-persist-client`, `@tanstack/query-sync-storage-persister` and the other `@tanstack/*query*` packages, all at the same version.

## Breaking changes

- **Old:** `useQuery(key, fn, opts)`, plus the same positional overloads on `useMutation`, `useInfiniteQuery`, `queryClient.fetchQuery`, `invalidateQueries`, `getQueryData` filters and so on.
  **New:** a single object, `useQuery({ queryKey, queryFn, ...opts })`. Filters are objects too: `invalidateQueries({ queryKey })`.
- **Old:** `cacheTime`. **New:** `gcTime`, with the same meaning. It also applies in `QueryClient` `defaultOptions`.
- **Old:** `useIsFetching(key)` / `useIsMutating(key)`. **New:** `useIsFetching({ queryKey })`.
- **Old:** `status: 'loading'` / `isLoading`. **New:** `status: 'pending'` / `isPending`.
  **Runtime-only:** `isLoading` still exists but now means `isPending && isFetching`. Code that used v4's `isLoading` to mean "no data yet" must use `isPending`.
- **Old:** `keepPreviousData: true`. **New:** `placeholderData: keepPreviousData`, imported from the package. `isPreviousData` became `isPlaceholderData`.
- **Old:** the `onSuccess` / `onError` / `onSettled` callbacks on `useQuery`. **New:** removed. Move the side effects into `useEffect` or the mutation callbacks. They still exist on mutations.
- **Old:** `useErrorBoundary`. **New:** `throwOnError`.
- **Old:** `suspense: true` on `useQuery`. **New:** `useSuspenseQuery` / `useSuspenseInfiniteQuery`.
- **Old:** infinite queries took the page param from `queryFn`'s default argument. **New:** `initialPageParam` is required, and `getNextPageParam` receives `(lastPage, allPages, lastPageParam)`.
- **Old:** `Hydrate`. **New:** `HydrationBoundary`. The `context` prop is gone; pass `queryClient` instead.
- **Old:** `remove()` on query results. **New:** `queryClient.removeQueries({ queryKey })`.
- **Old:** `TError` defaulted to `unknown`. **New:** it defaults to `Error`. The type-level `Register` interface can override it.

## Runtime-only changes to grep for

- `isLoading`: review every use. It's usually meant as `isPending`.
- `refetchInterval` / `refetchIntervalInBackground` functions now receive `query`, not `data`.
- `status === 'loading'` becomes `'pending'`. The type checker catches literals, but not values stored as strings.
- Custom `logger` option: removed, now goes to `console`.
